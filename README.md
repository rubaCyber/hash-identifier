# Hash Identifier

A simple Python-based cybersecurity learning project that identifies possible hash types based on their format, length, and known patterns.

## About This Project

This project was created as a hands-on learning experience to practice:

- Python programming
- Basic hash identification concepts
- Cybersecurity fundamentals
- GitHub repositories and version control
- Writing and organizing project documentation

The goal of this project is not to crack or decrypt hashes, but to identify their possible type based on common characteristics.

## Features

- Identifies common hash types
- Detects hexadecimal hash formats
- Supports:
  - MD5
  - SHA-1
  - SHA-224
  - SHA-256
  - SHA-384
  - SHA-512
  - bcrypt
  - Argon2
- Displays hash length
- Shows the detected format
- Provides a confidence level
- Includes a short description of the possible hash type
- Allows multiple hashes to be analyzed in one session
